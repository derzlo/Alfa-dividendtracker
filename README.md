# Дивидендный Трекер | Альфа-Инвестиции

Локальный веб-инструмент для анализа дивидендов, купонов и текущего портфеля по генеральному отчёту брокера «Альфа-Инвестиции».

## Особенности
* **Локальная безопасность:** Файл отчёта обрабатывается полностью в памяти вашего браузера и никуда не передаётся.
* **Автоматические котировки:** Интеграция с API Мосбиржи (MOEX ISS) для оценки текущей стоимости позиций.
* **Наглядная аналитика:** Графики выплат по годам (YoY), накопительный денежный поток, сезонность по месяцам и структура портфеля.

## Как запустить
1. Скачайте файл `portfolio_tracker_final.html`.
2. Переименуйте его в `index.html` (если хотите запустить через GitHub Pages).
3. Откройте в любом браузере (на ПК или смартфоне).
4. Перетащите в область загрузки свой `.xlsx` отчёт из Альфа-Инвестиций.
