# 📊 Дивидендный Портфель | Альфа-Инвестиции (v1.6)

Бесплатный, автономный веб-дашборд для углублённого анализа дивидендного портфеля на основе стандартного генерального отчёта «Альфа-Инвестиций» (.xlsx).

Работает прямо в браузере: данные никуда не передаются и обрабатываются строго локально на вашем устройстве.

---

## ✨ Возможности и функционал

* **Обзор портфеля и рыночные котировки:**
  * Автоматический расчёт текущей стоимости активов и прибыли/убытка от суммы покупок.
  * Интеграция с официальным API Московской биржи (MOEX) для обновления цен акций и фондов в реальном времени.
  * Сводка текущих позиций с расчётом долей, средней цены покупки и доходности на вложенный капитал (YOC LTM).
  * Анализ отраслевой диверсификации портфеля по секторам.

* **Дивидендная аналитика:**
  * Расчёт чистых выплат и удержанного налога (НДФЛ).
  * Динамика дивидендных выплат по годам (YoY) и помесячная статистика.
  * График накопительного денежного потока с удобными тултипами.
  * Прогноз выплат на следующие 12 месяцев (Forward Yield) на основе сезонности и истории.
  * Моделирование сложного процента при реинвестировании выплат.

* **Денежные потоки и движение средств:**
  * Раздельный учёт личных пополнений, выводов средств и удержанных брокерских комиссий.
  * Столбчатая диаграмма чистого движения капитала по годам.

* **Топ доноров дохода:**
  * Выделение ключевых активов, приносящих основной дивидендный поток.
  * Анализ концентрации капитала в топ-донорах.

* **Полный журнал операций:**
  * Интерактивная таблица всех сделок (покупки, продажи), пополнений, выводов, налогов и комиссий.
  * Фильтрация по типам операций, годам, конкретным тикерам и текстовый поиск.

---

## 🔒 Приватность и безопасность

* **Никаких бэкенд-серверов:** Весь парсинг Excel и расчёты происходят локально через JavaScript (SheetJS).
* **Никаких авторизаций:** Не требуется вводить логины, пароли или API-токены брокера.
* Брокерский отчёт не загружается в сторонние облака и остаётся только на вашем компьютере.

---

## 🚀 Как пользоваться

1. Выгрузите брокерский отчёт в приложении «Альфа-Инвестиции»:
   > **Главный** → нажмите на имя → **Действия** → **Отчёты** → **Заказ документов** → **Отчёт** → **Брокерский отчёт** (выберите формат `.xlsx` и нужный период, например «За всё время»).
2. Откройте страницу трекера в браузере.
3. Перетащите скачанный файл в окно трекера или нажмите кнопку **«Выбрать файл отчёта»**.
